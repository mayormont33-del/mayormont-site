Using these files

  • Keep all four files in the same folder. The maps link to each other by file name.
  • Open index.html (this page) in Chrome, Edge, Safari or Firefox on a computer. No internet connection is needed; with one, the brand fonts load too.
  • Full screen (⤢) is the best way to read a map on a small screen. Fit shows the whole map again.
